# Discourse deconstruction approaches

In addition to building familiarity with the new proposed model of the economy, familiarity should also be built with some of the fundamental issues with the existing economic model.  Some of these are very straightforward comparisons that will be immediately apparent when considering the benefits described earlier.  However, it would also be beneficial to build up a type of scepticism not with the particulars of the current system (that is, does it produce wealth inequality?), but the fundamental power-structures of the current system.  To achieve that, it would be useful to undertake a gentle process of discourse deconstruction.

- Do some people deserve to have lots while others don't have enough?
